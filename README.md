# 视频配音工具（DubTool 开源版）

给视频换配音的小工具：**先按波形把原视频切成一句一句的时间窗口，再把新台词合成语音逐采样点压回原窗口**，所以成品时长和原视频严丝合缝，字幕也跟着时间轴走。

不依赖任何 AI 助手、不联网识别、不上传你的视频——装好依赖后就是一个普通桌面程序。

> 这是从内部版本精简出来的**开源版**：移除了体积大、会抽卡、音质偏闷的本地 VITS 离线音色（约 120MB），只保留稳定、音质好的在线神经语音。想接自己的 AI 声音模型（CosyVoice / GPT-SoVITS / 自研引擎），看 [`docs/AI声音工具接入指南.md`](docs/AI声音工具接入指南.md)。

## 效果数据（实测，不是吹的）

拿一段真实视频反复跑，逐样本对比：

| 指标 | 结果 |
|---|---|
| 音轨时长漂移 | **0.0 ms** |
| 异常窗口 | **0 个** |
| 同一输入重复合成 | 逐样本完全一致（云端确定性推理） |
| 逐段响度离散 | 从 81% 降到 1.1% |
| 逐段高频比离散 | 从 153% 降到 34~44% |

核心原理在下面「它是怎么工作的」一节，实现细节都在 `core/` 里，注释写明了每处为什么这么写。

## 快速开始

### 1. 装依赖

双击 `安装依赖.bat`（需先装 Python 3.10+ 并勾选 Add to PATH）。它会装：

```
numpy  scipy  librosa  soundfile  edge-tts
```

再加一个 **ffmpeg**：要么装了并加进 PATH，要么把 `ffmpeg.exe` 路径填进 `config.json` 的 `ffmpeg` 字段。

### 2. 启动

双击 `启动.bat`。首次会看到界面，不弹命令行报错就是环境 OK。

### 3. 三步出片

1. **选视频**：点「输入视频/音频」浏览选文件，输出路径自动生成。
2. **填台词**：在「3 · 台词来源」选 `manual`，把台词**每行一句**粘进文本框（行数不用和句数一致，会自动按比例对齐）；或选 `srt` 导入现成字幕。
3. **点开始配音**：进度跑完，同目录生成成品 mp4、纯音频 mp3、台词 srt、时间轴 json、校验报告 json。

就这么简单。想调音色、语速、停顿，都在界面里，参数含义见下面表格。

## 它是怎么工作的

**配音模型从头到尾没听过原音频，只拿到文字。** 完整链路：

```
视频 ──ffmpeg──> 16k 单声道音轨
                    │
        ┌───────────┴────────────┐
        │                        │
   ① 波形/静音分析          ② 台词（手动 / SRT / 可选 ASR）
   切出每个发声窗口           每行一句 → 分配到各窗口
        └───────────┬────────────┘
                    ▼
   ③ 语速均衡（core/pace.py）：全片统一字速，重排文字切点
                    ▼
   ④ TTS 逐段合成（只输入文字）—— core/tts.py
                    ▼
   ⑤ 在 TTS 参数域精调每段语速，逐段频谱/响度匹配到全片参考谱
                    ▼
   ⑥ 裁剪/补零到精确采样点数压回原窗口 → 拼成整轨 → 封装视频
```

「一秒不差」靠的是**波形时间轴 + 采样点级对齐**，跟用什么 TTS 无关。**换音色、换引擎、甚至改台词，时间轴都不变**——这也是为什么能随意接 AI 声音工具。

### 为什么不会出现「忽快忽慢 / 忽清忽糊」

两个结构性缺陷叠加造成的，代码里都修了：

- **忽快忽慢**：旧版把整句台词按窗口数机械切字、再把波形强制铺满窗口，实测字数密度能差 1.88 倍。`core/pace.py` 改成全片统一字速、文字切点吸附标点、允许借静音/尾部留白，`voice_end` 取代窗口终点。
- **忽清忽糊**：旧版用相位声码器变速（把部分片段的频谱抹糊）+ 逐段 tanh 限幅（非线性失真）+ 按峰值归一。`core/align.py` 改成只在 TTS 参数域调语速、波形不做相位拉伸、用全片参考谱中位数做频谱匹配、RMS 响度对齐。

## 界面速查

| 区域 | 作用 |
|---|---|
| 1 · 文件 | 选输入视频/音频、成品路径；「复用时间轴」加载上次生成的 json 改文字重跑 |
| 2 · 声音 | 选音色、试听、语速、音调 |
| 3 · 台词来源 | `manual` 手动每行一句 / `srt` 导入字幕 / `sensevoice` 离线识别（需另下模型） |
| 4 · 参数 | 句子间隔、静音阈值、语速均衡、音色一致、锁定缓存等 |
| 5 · 运行 | 开始 / 取消 / 进度 / 日志 / 打开输出目录 |

## 参数（界面里都能改）

| 参数 | 默认 | 含义 |
|---|---|---|
| 句子间隔 | 0.60s | 静音 ≥ 此值判定为句子分界 |
| 最短静音 | 0.20s | 短于此的静音并入发声段，不切窗口 |
| 静音阈值 | -38dB | 叠加自适应阈值，适配不同响度素材 |
| 语速 | -4% | 基础语速；逐段还会自动精调 |
| 音调 | -2Hz | 越低越沉稳 |
| 合成并发 | 4 | 在线语音并发请求数 |
| 语速均衡 | 开 | 消除忽快忽慢；关掉退回旧行为 |
| 可借静音 | 0.90s | 单段最多向后借多少秒静音 |
| 音色一致 | 开 | 逐段频谱/响度匹配到全片参考谱 |
| 匹配强度 | 0.85 | 0~1；1 为完全拉齐，限幅 ±4dB |
| 允许波形变速 | 关 | 旧行为，会让部分片段发蒙，仅 A/B 对照用 |
| 锁定合成结果 | 开 | TTS 波形磁盘缓存，逐样本可复现、断网可复跑、重跑免请求 |

## 输出文件

以 `1.mp4` 为例，同目录生成：

| 文件 | 内容 |
|---|---|
| `1_配音.mp4` | 成品，画面原样拷贝，只换音轨 |
| `1_试听.mp3` | 纯音频，快速听 |
| `1_台词.srt` | 按时间轴生成的字幕 |
| `1_时间轴.json` | 每段的起止时间、台词、实际发声终点；**改 text 后可复用重跑** |
| `1_校验报告.json` | 漂移、每段 RMS、异常窗口数 |

## 只改一句台词，不重新识别

1. 第一次跑完，在输出目录找到 `*_时间轴.json`；
2. 记事本打开，改某段的 `text`（要锁住这段的时长就加 `"locked": true`）；
3. 界面「复用时间轴」选这个文件 →「开始配音」。

时间轴不动，只重合成语音，漂移依旧是 0。

## 可选：离线语音识别（SenseVoice）

默认台词用手动输入或 SRT，不需要任何模型。想要「视频里说的自动转成文字」：

1. 下载 sherpa-onnx 的 SenseVoice 模型（约 230MB，如 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`）；
2. 把 `model.int8.onnx` 和 `tokens.txt` 放进 `models/sensevoice/`；
3. 界面「台词来源」选 `sensevoice`。

模型不随软件分发，自己下载放进去即可。

## 常见问题

- **提示缺模块** → 双击 `安装依赖.bat`。
- **提示 ffmpeg 找不到** → 装 ffmpeg 加进 PATH，或在 `config.json` 填 `ffmpeg` 绝对路径。
- **识别不准** → 直接用 `manual`（每行一句）或 `srt` 导入，结果本来就会回填供修改。
- **要多音字校准** → 点「打开读音校准表」，在 `pron_fix.json` 写 `"圈": "全"`（只改发音，字幕不变）。
- **想接自己的 AI 声音** → 看 [`docs/AI声音工具接入指南.md`](docs/AI声音工具接入指南.md)。

## 目录结构

```
DubTool/
├── 启动.bat / 安装依赖.bat   双击即可
├── app.py                    图形界面
├── config.json               参数持久化（首次运行生成）
├── pron_fix.json             多音字读音校准表
├── core/
│   ├── extract.py            抽音轨
│   ├── vad.py                波形静音切分 + 句子分组
│   ├── asr.py                台词来源（manual / srt / 可选 SenseVoice）
│   ├── tts.py                合成引擎（edge-tts，可插拔 ← 接 AI 声音改这里）
│   ├── voices.py             音色库
│   ├── tts_cache.py          合成结果磁盘缓存
│   ├── pace.py               语速均衡
│   ├── align.py              采样点对齐 + 频谱/响度匹配
│   ├── mux.py                封装 + 校验 + 报告
│   ├── pron.py               多音字校准
│   └── config.py            配置加载
├── docs/
│   └── AI声音工具接入指南.md   CosyVoice / GPT-SoVITS / 自研引擎接入
├── models/sensevoice/        可选：自己下载的离线识别模型
├── work/                     中间文件（自动生成）
└── 输出/                      成品默认目录
```
